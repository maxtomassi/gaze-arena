# Asset pipeline

## What goes where
| Kind | How it's made | Where it lives |
|---|---|---|
| Characters (footballers, wrestlers, referee) | SVG parts drawn in code, animated with Phaser tweens | `packages/kit/src/art/` |
| Buttons, icons, bars, banners | Drawn in code (SVG / Phaser graphics) | kit, or the game if game-specific |
| Confetti, fireworks, flashes, shake | Phaser particles and camera effects | game code |
| Backgrounds, static illustrations | Generated by `tools/asset-gen` from `assets.yaml` | `games/<id>/public/assets/img/` |
| Sound effects | CC0 packs (e.g. Kenney, Freesound CC0) | kit `audio/common/` or game `public/assets/audio/` |
| Voice lines ("GOAL!", referee count) | Generated by text-to-speech from `assets.yaml`, per locale | `public/assets/audio/<locale>/` |

Rule of thumb: if it moves, it's drawn in code.

## Manifest: `games/<id>/assets.yaml`
```yaml
style: arena-night
assets:
  - id: stadium-night            # unique within the game
    type: image                  # image | voice
    out: public/assets/img/stadium-night.webp
    size: [1920, 1080]           # final size after post-processing
    transparent: false           # true → background removal step
    prompt: >                    # scene only; style comes from the style folder
      Wide view of a football stadium at night ...
  - id: chant-goal
    type: voice
    text: { en: "GOOOAL!", it: "GOOOL!" }
    out: public/assets/audio/{locale}/chant-goal.mp3
```

## Shared styles: `tools/asset-gen/styles/<style>/`
- `style.md` — the style prompt prepended to every image prompt (outlines, palette, proportions, "no text, no logos, no real brands").
- `refs/` — 2–5 reference images sent with each request to keep the look consistent.
- `voice.yaml` — voice settings per locale for text-to-speech.

## What `npm run assets -w games/<id>` does
1. Reads the manifest and the style; skips assets whose output file exists and whose
   prompt hash matches `assets.lock.json` (use `--force <id>` to regenerate).
2. Calls the configured provider (adapter interface in `tools/asset-gen/providers/`; API key from `.env`, never committed).
3. Post-processes: background removal when `transparent: true`, resize/crop to `size`, convert to WebP (images) or MP3 (audio).
4. Writes the file, updates `assets.lock.json` (prompt hash, provider, model, date) and appends or updates the entry in the game's `ASSETS.md`.
5. Prints a contact sheet (`tools/asset-gen/out/<id>-review.html`) so a human can review before committing.

## Providers
- Default image provider: **OpenAI `gpt-image-2`** (adapter `providers/openai.ts`, key `OPENAI_API_KEY` in `.env`).
  Requires an OpenAI API account with billing; a ChatGPT subscription does not include API credits.
- Request opaque images and rely on our own background-removal step when `transparent: true`,
  rather than on provider transparency support.
- The style may set `provider` and `model`; individual assets may override them.
- Other providers can be added as adapters, after checking their output terms. Note: Recraft's terms forbid using
  its outputs to train AI models on any plan, which conflicts with permissive licenses for redistributed assets.

## Rules
- Generated files and `assets.lock.json` are committed. Nothing is generated at build, dev or test time.
- Every scene must run without its generated files, using a code-drawn fallback.
- Before adding a provider, check its terms allow redistribution of outputs under the repo's license.
- `ASSETS.md` records, for each generated file: provider, model, prompt, date and license statement.
- No real people, brands, leagues, wrestlers or logos in prompts or outputs; review every image before committing.
